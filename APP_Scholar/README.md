# APP_Scholar
Versionamento e posts relacionados ao desenvolvimento do APP_Scholar feito no Snack.

## Sobre o projeto
O APP Scholar é um projeto desenvolvido a partir da requisição de um aplicativo que fizesse uma ligação com o banco de dados escolar,
que fosse capaz de cadastrar novos alunos, professores, coordenadores, etc. Fazer a consulta dos mesmos e que fosse capaz de modificações
simples dentro dos limites pré-definidos no aplicativo, dando total controle sobre oque acontece no banco de dados escolar(bd_escola).

## Estrutura do projeto
O projeto usa uma estrutura simplificada, separando as paginas de ação e consulta na pasta "pages", com o app principal fora desta.
Já as imagens e arquivos de mídia externos utilizados no código estão localizados na pasta "assets";
A pasta "components" e alguns outros arquivos são padronizados da plataforma Snack, não foram apagados.

## Como executar
Para executar o projeto basta baixar a pasta "app-scholar" e suas dependencias na pasta indicada, no caso atual de desenvolvimento (Postado em 25/09/2026) o projeto não tem dependências ainda.
Após baixar os arquivos e a estrutura de paginas corretamente, os itens devem ser importados para o Snack -* https://snack.expo.dev/ *-
seguindo a estrutura de pastas, que não foi modificada, apenas adicionada a pasta "pages", o Snack deve funcionar perfeitamente apenas 
com as instruções acima.
